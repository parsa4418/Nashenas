# MeloGap Replica — رپلیکای ربات چت ناشناس ملوگپ

بازسازی **از صفر** ربات `@MeloGap` بر اساس رفتار ظاهری مشاهده‌شده در بررسی زنده.
این پروژه سورس اصلی ربات نیست؛ بک‌اند (دیتابیس کاربران واقعی، درگاه پرداخت واقعی) وجود ندارد و بخش‌های لازم به‌صورت استاب پیاده شده‌اند.

A **from-scratch replica** of the `@MeloGap` anonymous-chat bot, built only from publicly observed behaviour. It is not the original source code.

## اجرا / Run

```bash
cd melogap-replica
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # توکن ربات خودت رو از @BotFather بذار
# load env (یا با python-dotenv / systemd EnvironmentFile)
export $(grep -v '^#' .env | xargs)
python3 bot.py
```

## کانفیگ / Config (`.env`)

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات خودت از BotFather (هرگز منتشرش نکن) |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، جداشده با کاما — برای `/admin` |
| `REQUIRED_CHANNELS` | کانال‌های عضویت اجباری، پیش‌فرض `@Dosti,@MeloGapM` |
| `BOT_USERNAME` | یوزرنیم ربات تو (پیش‌فرض `MeloGap`) — در لینک دعوت `/link` استفاده می‌شود |
| `PAYMENT_GATEWAY_URL` | **placeholder استاب** — لینک واقعی درگاه ربات اصلی استفاده نشده است |

## چه چیزهایی پیاده شده / Implemented

- آنبوردینگ کامل: جنسیت (دکمه‌های سبز اینلاین) → سن ۹ تا ۹۹ (۶ تا در هر ردیف) → ۳۱ استان (۳ تا در هر ردیف) → شهر؛ هدیه تکمیل پروفایل +۵ سکه
- لینک دعوت `/start inv_<code>`:‏ +۲۰ سکه هنگام ورود دعوت‌شده و +۱۰ سکه دیگر هنگام تکمیل پروفایل او (مجموع ۳۰) — ناهماهنگی ارقام مشاهده‌شده در ربات اصلی در کامنت‌های بالای `bot.py` مستند شده
- منوی اصلی دقیقاً با چیدمان و استایل‌های Bot API ‏(`success` سبز / `primary` آبی) ربات اصلی
- گیت عضویت اجباری با دکمه‌های URL سبز و دکمه «♻️ بررسی عضویت و فعال سازی ♻️» (+ آلرت عدم عضویت)؛ دستورات `/help*`‏، `/credit`‏، `/id`‏، `/link`‏، `/profile`‏، `/silent` از گیت عبور می‌کنند (مطابق مشاهده)؛ ادمین و کاربران Exempt معاف‌اند
- `/Exempt` با متن ۱۵٬۰۰۰ تومان/۱ سال/+۲۰ سکه و دکمه پرداخت — **نکته:** لینک پرداختی که ربات اصلی تولید می‌کرد ۵۵٬۰۰۰ تومان بود؛ هر دو عدد به‌صورت کانستنت جدا (`EXEMPT_PRICE_DISPLAY` / `EXEMPT_PRICE_CHARGE`) در کد نگه داشته شده‌اند
- سیستم راهنما: `/help` و ۱۳ دستور `/help_*` با پشتیبانی `@melogapSupport`
- سکه، خرید با Telegram Stars (فاکتور XTR) — بسته‌ها: ۳۲۰←۱۲۰⭐، ۵۴۰←۱۹۰، ۱۵۰۰←۲۸۰، ۲۸۰۰←۴۰۰، ۶۸۰۰ VIP←۷۵۰
- `/link`‏، `/id`‏، `/profile` با همه زیرمنوها: GPS، لایک‌کننده‌ها، مخاطبین، بلاک‌شده‌ها، تنظیمات پیشرفته (سایلنت ۳۰دقیقه/۱ساعت/همیشه، فیلتر درخواست چت، آلارام‌ها)، ویرایش پروفایل (نام/جنسیت/شهر/سن/GPS/عکس)
- پروفایل دیگران با `/user_<code>`: درخواست چت (۲ سکه فقط هنگام قبول؛ رد خودکار برای سایلنت/آفلاین بیش از ۱۵ دقیقه)، پیام دایرکت (۱ سکه، حداکثر ۲۰۰ کاراکتر، لغو با «بیخیال»)، لایک، مخاطبین، بلاک، گزارش (اطلاع به ادمین)، اطلاع آنلاین‌شدن/پایان چت (هرکدام ۱ سکه، اعتبار ۱۰ روز)
- چت ناشناس: صف جستجو (شانسی رایگان / دختر و پسر ۲ سکه / اطراف رایگان / همسن)، رله همه نوع پیام با `copy_message`، حذف پیام‌ها با `deletall` / «حذف همه» (۱۰۰ پیام آخر)، دکمه پایان چت و پروفایل طرف مقابل
- جستجوی کاربران و افراد نزدیک از روی دیتابیس (هم‌استانی/هم‌سن/بدون‌چت/جدید/پیشرفته)
- `/deleted_account` (۳۰٬۰۰۰ تومان — پرداخت استاب؛ دکمه تأیید استاب رکورد کاربر را حذف می‌کند)
- `/contacts` و پنل `/admin`: آمار، ارسال همگانی، افزودن/کم‌کردن سکه با کد کاربر
- دکمه‌های رنگی: همه دکمه‌های اینلاین به‌صورت پیش‌فرض `style="success"` (سبز) هستند؛ هِلپرهای `gbtn()/pbtn()/dbtn()`

## استاب‌ها و محدودیت‌ها / Stubs & limitations

- **درگاه پرداخت ریالی (`/Exempt` و `/deleted_account`): استاب است.** فقط پیام نکات پرداخت و یک دکمه URL به `PAYMENT_GATEWAY_URL` (placeholder) نمایش داده می‌شود؛ لینک واقعی ربات اصلی عمداً استفاده نشده. فعال‌سازی خودکار Exempt بعد از پرداخت پیاده نشده (به‌صورت دستی از دیتابیس/ادمین قابل تنظیم است).
- **ایموجی پرمیوم دکمه‌ها:** Bot API از `icon_custom_emoji_id` پشتیبانی می‌کند و هِلپرها سیم‌کشی شده‌اند، اما آیدی ایموجی‌های کاستوم ربات اصلی از تلگرام وب **قابل استخراج نیست**؛ دیکشنری `PREMIUM_EMOJI` در بالای `bot.py` خالی (placeholder) است — آیدی‌های ربات خودت را آنجا بگذار.
- **لیست شهرها:** فقط لیست کامل شهرهای استان تهران از ربات اصلی مشاهده شد؛ برای بقیه استان‌ها لیست معقول (مرکز استان + شهرهای اصلی) گذاشته شده است.
- **صفحه‌های زنده پشت گیت:** صفحه‌های اصلی جستجو/افراد نزدیک/اتصال در بررسی زنده به‌خاطر گیت عضویت دیده نشدند؛ زیرمنوهایشان از متن‌های `/help_*` و تصاویر راهنمای خود ربات بازسازی شده‌اند.
- صف جستجو و چت‌های فعال در حافظه‌اند (با ری‌استارت پاک می‌شوند)؛ کاربران، سکه‌ها و تنظیمات در SQLite (`bot.db`) ذخیره می‌شوند.
- بررسی عضویت گیت: اگر ربات در کانال ادمین نباشد یا API خطا بدهد، کاربر بلاک نمی‌شود (در لاگ هشدار ثبت می‌شود) تا در محیط تست قفل نشوی — برای محیط واقعی، ربات را در کانال‌ها ادمین کن.
